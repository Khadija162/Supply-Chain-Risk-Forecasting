# Openly licensed demonstration dataset

`supply_chain_synthetic.csv` contains 600 original, synthetic supply-chain observations generated by `python -m src.dataset`. These records are released under **CC0 1.0** and may be reused without restriction. The columns are date, supplier_id, lead_time_days, daily_demand, inventory_units, supplier_on_time_rate, transport_delay_days and disruption_risk.

**Important:** This is *not measured real-world supply chain data*. The `disruption_risk` target is produced using an artificial rule from the predictors. Therefore an apparently high ML score does not establish real-world forecasting ability. For future external validation, incorporate publicly licensed actual shipments, weather, port congestion or logistics data with clear provenance and leakage controls.
